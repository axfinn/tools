**修复**:

- 添加参数验证和使用说明

## 修复的功能问题

### 2. remove 命令协议参数支持 🔧 高优先级
**文件**: `port-protect.sh:601-646`

**问题**:
- remove 函数接受协议参数但未在命令行解析中实现
- 无法移除 UDP 端口规则
- 无法指定自定义链名称

**修复**:
- 添加了 `--protocol` / `-p` 参数支持
- 添加了 `--chain` / `-c` 参数支持
- 更新了帮助文档

**新用法**:
```bash
# 移除 UDP 端口
sudo ./port-protect.sh remove 8080 --protocol udp

# 移除指定链的端口
sudo ./port-protect.sh remove 8080 --chain MY_CUSTOM_CHAIN
```

### 3. status 命令不显示独立链 🔧 高优先级
**文件**: `port-protect.sh:527-573`

**问题**:
- status 命令只检查旧版共享链 DOCKER-HOST-PROTECT
- 新版默认的独立链（DOCKER-HOST-PROTECT-<port>）不会显示

**修复**:
- 改为动态检测所有相关链（包括共享链和独立链）
- 显示每个链的详细规则
- 显示 INPUT 链中的引用关系
- 集成 list-ports 功能显示端口概览

**改进效果**:
```
当前端口保护状态:
========================================
发现以下防护链:

链名称: DOCKER-HOST-PROTECT-19099
----------------------------------------
Chain DOCKER-HOST-PROTECT-19099 (1 references)
...

受保护端口概览:
----------------------------------------
链: DOCKER-HOST-PROTECT-19099  端口: 19099/tcp
链: DOCKER-HOST-PROTECT-19100  端口: 19100/tcp
```

### 4. RDP 模式参数处理逻辑 🔧 中优先级
**文件**: `port-protect.sh:272-371`

**问题**:
- `--rdp` 标志硬编码覆盖 limit 和 burst，用户无法自定义
- 文档说明参数顺序重要，但实际上无论顺序都会被覆盖

**修复**:
- 改为先解析所有参数，后设置默认值
- 只在用户未指定时才使用模式默认值
- 优先级: 用户指定 > 模式默认 > 全局默认

**改进效果**:
```bash
# 现在参数顺序不再重要，以下写法等效
sudo ./port-protect.sh add 19099 --rdp -l 20/min -b 25 -t 1.2.3.4
sudo ./port-protect.sh add 19099 -l 20/min --rdp -t 1.2.3.4

# 用户指定的值优先，不会被模式默认值覆盖
```

## 修复的安全问题

### 5. 备份文件权限 🔒 中优先级
**文件**: `port-protect.sh:154-169, 210-216`

**问题**:
- 备份文件可能包含敏感的防火墙规则信息
- 未设置适当的文件权限

**修复**:
- 创建备份后自动设置 600 权限（仅 owner 可读写）
- 更新当前备份时也设置权限
- 恢复前备份同样设置权限

**安全改进**:
```bash
# 备份文件现在默认权限为 600
-rw------- 1 root root  12345 Oct 28 10:00 iptables_backup.rules
```
