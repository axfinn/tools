# 更新日志 - blacklist-manager.sh v3.0.0

## 版本 3.0.0 - Debian/Ubuntu 优化版本 (2025-10-29)

### 重大改进

#### 1. 依赖管理系统
- **自动安装依赖**: 新增 `install-deps` 命令，自动检测并安装所需包
- **智能包检测**: 使用 `dpkg -l` 精确检查包安装状态
- **操作系统检测**: 自动识别 Debian/Ubuntu 系列发行版
- **内核模块自动加载**: 自动检查并加载 `ip_set` 相关内核模块
- **详细错误提示**: 缺少依赖时提供清晰的解决方案

#### 2. 改进的错误处理
- **严格错误模式**: 使用 `set -euo pipefail` 提高脚本健壮性
- **详细错误诊断**: 捕获并显示 ipset/iptables 的详细错误信息
- **诊断命令**: 新增 `diagnose` 命令，全面检查系统状态
- **调试模式**: 支持 `DEBUG=1` 环境变量启用详细日志
- **友好错误消息**: 所有错误都包含可能原因和解决方案

#### 3. Debian/Ubuntu 兼容性修复
- **stat 命令修复**: 使用 `-c` 选项替代 macOS 的 `-f` 选项
- **apt 包管理**: 使用 `apt-get` 和 `DEBIAN_FRONTEND=noninteractive`
- **dpkg 集成**: 精确的包安装状态检查
- **系统路径**: 遵循 Debian/Ubuntu 的目录结构规范

#### 4. 持久化支持
- **netfilter-persistent 集成**: 自动使用系统持久化服务
- **ipset 保存/恢复**: 新增 `save` 和 `restore` 命令
- **保存文件**: 统一保存到 `/etc/iptables/ipsets`
- **init 自动保存**: 初始化时自动保存配置
- **开机自动恢复**: 支持 netfilter-persistent 和 systemd

#### 5. 日志管理优化
- **logrotate 配置**: 提供标准的 logrotate 配置文件
- **改进的日志轮转**: 修复日志大小检测逻辑
- **日志清理增强**: cleanup 命令提供更详细的反馈
- **权限管理**: 自动设置正确的日志文件权限 (600)

#### 6. 用户体验提升
- **彩色输出**: 使用 ANSI 颜色增强可读性
- **版本信息**: 显示脚本版本号
- **格式化帮助**: 使用 heredoc 改进帮助信息布局
- **进度反馈**: 所有操作都有清晰的状态反馈
- **友好提示**: init 后显示下一步操作建议

#### 7. 诊断功能
新增全面的系统诊断命令，检查：
- 操作系统版本和内核版本
- 依赖包安装状态和版本
- 内核模块加载状态
- ipset 集合详细信息
- iptables 规则配置
- 日志文件状态和权限
- 持久化配置状态

#### 8. 命令行界面改进
- **灵活的权限检查**: help 和 diagnose 不强制 root 权限
- **更好的命令路由**: 优化主函数的命令分发逻辑
- **参数验证**: 所有命令都有完整的参数检查
- **退出码**: 正确设置命令执行的退出码

### 迁移指南

如果你正在使用旧版本：

1. 备份当前 ipset（可选）:
   ```bash
   sudo ipset save port-protect-blacklist > ~/ipset-backup.txt
   ```

2. 替换脚本文件:
   ```bash
   cp blacklist-manager.sh.v3 blacklist-manager.sh
   ```

3. 继续使用，无需修改工作流

### 系统要求

- **最低内核版本**: 3.10+ (推荐 4.15+)
- **操作系统**: Debian 10+, Ubuntu 18.04+
- **内存**: 最小 512MB
- **磁盘空间**: 最小 100MB（用于日志）

### 性能特性

- 支持 65536 个 IP 地址（ipset 默认）
- O(1) 查找时间复杂度
- 最小内存占用（约 1-2MB）
- 无性能影响的防火墙规则

### 已知限制

1. 不支持 IPv6（计划在 v3.1.0 添加）
2. timeout 精度为秒（ipset 限制）
3. 需要内核支持 netfilter 和 ipset
