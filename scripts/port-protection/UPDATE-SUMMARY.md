# 更新摘要

## 主要改进

### 1. 新增RDP优化模式
- 添加 `--rdp` 参数，专为RDP等长连接协议优化
- 自动调整速率限制为30/min，突发限制为50
- 允许已建立连接无限制通过
- 解决RDP连接在添加防护规则后无法使用的问题

### 2. 新增白名单模式
- 添加 `--whitelist-only` 参数，提供最严格的访问控制
- 仅允许指定的可信IP访问，直接拒绝其他连接
- 适用于SSH、数据库等高安全性要求的服务

### 3. 文档完善
- 更新README.md，添加新功能说明和使用示例
- 新增RDP使用指南(RDP-USAGE.md)
- 添加故障排查和最佳实践建议

## 使用建议

### RDP端口保护
```bash
# 推荐方案1: RDP优化模式
sudo ./port-protect.sh add 19099 --rdp -t 你的IP地址

# 推荐方案2: 白名单模式(最安全)
sudo ./port-protect.sh add 19099 --whitelist-only -t 你的IP地址
```

### 不同服务的保护策略
- **RDP/VNC**: 使用 `--rdp` 或 `--whitelist-only` 模式
- **SSH**: 推荐 `--whitelist-only` 模式
- **Web服务**: 使用默认模式，适当调整限制参数
- **API服务**: 使用严格的速率限制或白名单模式

## 向后兼容性

所有现有功能保持不变，新增参数为可选项，不影响现有脚本的使用。
